1. Problem Framing & Assumptions

Vertical short-form drama platforms (TikTok, Reels, Shorts) rely entirely on hook retention to drive episode purchases. Discovering viral promotional cut points across 50 full-length episodes (~3,700 script events) is manually grueling. Naive LLM windowing fails in production due to dialogue slicing (cutting mid-speech), context collapse (unresolved pronouns like "He betrayed her"), continuation spoilers (a promo that answers its own cliffhanger), and late-series narrative spoilage.

Hard Editorial Invariants

  • Duration: Strictly bounded to 20.0s – 60.0s total runtime.
  • Dialogue Boundary Validation: Zero cuts inside spoken dialogue lines (<0.1s tolerance; text-only boundary check).
  • Curiosity Hook & Gap: Opening hook in first 3.0s; ends on unresolved tension.
  • Confidentiality: Zero proprietary screenplay text committed to public git.

Human-in-the-Loop Philosophy

AI proposes, ranks, and annotates; deterministic code guarantees timing invariants and boundary physics; human editors review, approve, re-trim on real line boundaries, and resolve flagged AI-heuristic disagreements.

Editorial clarification: These reference windows represent an LLM-generated reference benchmark, not human editorial ground truth or a manually labeled gold set. While shortlist allocation affected candidate availability, it does not conclusively explain the entire gap; semantic divergence in hook and cliffhanger valuation between LLM architectures also drives differing editorial choices.

Failure Mode Retrospective & Applied Fixes

  • 1. Standalone Disagreement Bug: 17 of 25 promos had high AI standalone scores (≥80) but were flagged with heuristic "needs context" because regexes flagged missing pronouns. Fix: Reconciled in UI by surfacing Context Review Needed (AI Disagreement) with an explicit explanatory tooltip instead of corrupting the score.
  • 2. EP_027 Duplicate 5.4s Shared Beat: Two cuts in EP_027 shared 5.4s of a confrontation beat because relative overlap was 14.7% ≤ 20%. Fix: Enforced an absolute ≥4.0s overlap threshold alongside relative >15%, eliminating duplicate beat reuse across all episodes.
  • 3. Quiet Romance Episode Infiltration: Low-stakes domestic conversations (EP_006, EP_014, EP_017) snuck into rule ranks. Fix: Implemented soft dialogue damping for clips with romance markers and zero escalation, eliminating them from the top 25 global promos.
  • 4. Editorial Counter Overwrite: Approving a single promo in the UI overwrote engine candidate counts. Fix: Separated engine inventory (candidates_accepted) from human curation counts (user_approved, user_rejected, user_pending).

5. Tools Used & Where AI Got It Wrong

Tooling Stack

TypeScript 5.7, React 19, Tailwind CSS v4, Vite 8, Python 3.12, FastAPI, OpenTimelineIO (OTIO), CMX 3600 EDL, and Google Gemini API (gemini-3.1-flash-lite) with offline rule fallback.

Where AI Failed in Practice

  • Clock Math Hallucinations: LLMs failed at decimal-second durations (e.g. 01:12.40 to 01:45.10). Fix: Time arithmetic is 100% computed in integer milliseconds by deterministic code.
  • Confidence Inflation: Early prompts caused 90% of clips to score 88–95. Fix: Rubric-based scoring with explicit structural penalties.

6. Next Steps & Production Limitations

  1. Text-Only Screenplay Modality Limitation: PromoForge operates strictly on parsed timestamped screenplay text. Dialogue boundary safety is validated against script event start and end clocks, not direct audio waveform or acoustic phoneme analysis. Non-verbal visual acting beats and unscripted audio cues require human editor review.
  2. Audio-Visual Multimodal Grounding: Ingest proxy video alongside text screenplays to correlate dialogue with facial close-ups, vocal loudness spikes, and scene cuts via Whisper timestamps.
  3. Cross-Episode Multi-Segment Stitching: Expand the built-in createMultiSegmentPromo engine to automatically pair Episode 1 curiosity hooks with Episode 15 cliffhangers into seamless 45-second composite narrative teasers.
  4. Real-Time Retention Feedback Loop: Connect TikTok/Reels retention curve APIs via webhook to continuously tune hook scoring weights against real audience drop-off data.
